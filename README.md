Live Portfolio built with React, Vite, Tailwind CSS, Lucide React, and Recharts.

---

## 🚀 Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (Dark / Light Theme support)
- **Charts & Visualizations:** Recharts
- **Icons:** Lucide React
- **Deployment:** Render (Static Site)

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/RuthalaChandrika/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be available at `http://localhost:3000`.

---

## 🌐 Deploy on Render

This project includes a `render.yaml` configuration for seamless one-click static site deployment on [Render](https://render.com).

### Render Configuration:
- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `./dist`
- **Routing:** SPA Rewrite (`/* -> /index.html`)
